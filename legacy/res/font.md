U+e000 - U+e006 => 0-6 normal
U+e007 - U+e00b => 1-5 with uniform bar
U+e00c - U+e010 => 1-5 with rightward extending bar
U+e011 - U+e015 => 1-5 with leftward extending bar

The english letters and apostrophe are encoded to their respected key.
The english letters are shortened in height so that they match with the height of the numbers.

the reason for 3 different bar designs is when the rightwards extending bar numbers and leftward extending bar characters sit side by side they create the illusion that they have one continuous bar.

The whitespace character is not shortened, so we need to use a different unicode whitespace character.
